# SWOT/TOWS Pre-Delivery Checklist

Run through this before delivering. Fix anything that fails.

## Scoping
- [ ] The subject (company/product/team/decision) is explicitly named.
- [ ] The goal or decision the SWOT serves is stated.
- [ ] The time frame and scope are clear.

## Quadrant correctness
- [ ] Every Strength is INTERNAL and TRUE TODAY and a relative advantage.
- [ ] Every Weakness is INTERNAL and in principle fixable by the subject.
- [ ] Every Opportunity is EXTERNAL and an exploitable change (not a goal/wish).
- [ ] Every Threat is EXTERNAL and outside the subject's control.
- [ ] No factor is miscategorized (the classic: external trend listed as a strength/weakness).

## Factor quality
- [ ] No vague adjectives standing alone ("strong brand", "good team").
- [ ] Each factor is specific; quantified where data exists.
- [ ] Each strength/weakness names a cause; each opportunity/threat names a trend.
- [ ] Assumptions are tagged as assumptions, not stated as facts.
- [ ] Each quadrant has 4-8 items, ranked, not an unfiltered list.

## Prioritization
- [ ] Each factor scored on Impact (1-5) and Confidence/Likelihood (1-5).
- [ ] Top items per quadrant are visually prominent.

## TOWS / strategy
- [ ] A TOWS matrix was produced.
- [ ] At least one strategy per applicable cell (S-O, S-T, W-O, W-T).
- [ ] Each strategy names the specific factors it combines.
- [ ] Existential W-T risks are surfaced and addressed first.

## Actions
- [ ] Top strategies converted to actions with What / Why / Owner / Horizon / Metric.
- [ ] Actions are sequenced, not a flat dump.

## Conclusion
- [ ] A recommended strategic posture is stated (Aggressive / Defensive / Turnaround / Survival).
- [ ] The single most important next move is called out.
