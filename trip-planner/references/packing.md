# Packing Checklist Reference

Drive the list from three variables: **climate/season**, **trip length**, and **planned activities**. Below is a modular checklist — include only the modules that apply.

## Core (every trip)
- Passport / ID + photos or copies (digital + paper)
- Visas / entry docs / vaccination records if required
- Payment: 2 cards (different networks), some local cash, backup card stored separately
- Phone + charger; universal power adapter; power bank
- eSIM/SIM plan sorted
- Medications (in carry-on, original packaging) + small first-aid kit
- Reusable water bottle
- Toiletries (travel sizes if carry-on only)
- Booking confirmations (offline copies): flights, lodging, tours, insurance
- Travel insurance details + emergency contacts

## Clothing baseline (adjust count to trip length)
Rule of thumb: pack for ~7 days max and do laundry on longer trips.
- Tops: 1 per 1.5 days
- Bottoms: 2–3 mix-and-match
- Underwear/socks: days + 2
- 1 layer (cardigan/fleece) regardless of climate (planes, AC, evenings)
- Comfortable walking shoes (broken in) + 1 alternate pair
- Sleepwear

## Climate modules
**Hot / tropical**: breathable fabrics, sun hat, sunglasses, high-SPF sunscreen, insect repellent, light rain layer (monsoon), swimwear, sandals.

**Cold / winter**: insulated jacket, thermal base layers, hat/gloves/scarf, warm socks, waterproof boots, lip balm, moisturizer.

**Shoulder season / variable**: layers, packable rain jacket, compact umbrella, both warm and cool options.

## Activity modules
**Hiking/outdoors**: trail shoes/boots, daypack, moisture-wicking layers, blister care, headlamp, refillable bottle, dry bag.

**Beach/water**: swimwear x2, quick-dry towel, rash guard, reef-safe sunscreen, waterproof phone pouch.

**City/culture**: smart-casual outfit for nicer restaurants, modest layer for religious sites (covered shoulders/knees), crossbody anti-theft bag.

**Business**: wrinkle-resistant formalwear, laptop + charger, documents.

## Family / kids module
- Snacks, refillable cups, entertainment (downloaded media, small toys)
- Extra clothes per child (accidents), wet wipes
- Stroller/carrier as appropriate; car seat if driving
- Any comfort items (sleep critical)

## Pre-departure 48h checklist
- Check passport validity (many countries require 6 months beyond travel)
- Confirm visa / entry requirements
- Notify bank of travel / check card foreign fees
- Download offline maps + translation + booking confirmations
- Check weather forecast and re-tune clothing
- Arrange home logistics (mail, pets, plants)
- Set up airport transfer for arrival
- Charge all devices; pack chargers in carry-on

## Carry-on essentials (never check these)
Medications, documents, one change of clothes, valuables/electronics, chargers, glasses/contacts. Assume checked luggage can be delayed.
