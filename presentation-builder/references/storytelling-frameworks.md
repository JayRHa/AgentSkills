# Storytelling Frameworks for Presentations

Deep reference for Step 3 (choose an arc) and Step 2 (lock the core message). Load this when picking a structure or when a deck feels like a flat list of facts.

## The Core Message Test

The core message is the ONE sentence the audience should repeat tomorrow. It must:

1. Be a **complete declarative sentence** (subject + verb + point), not a topic. 
   - Bad: "Our Q3 results."
   - Good: "Q3 proved the new pricing works — so we should roll it out company-wide."
2. Contain a **point of view** (something a reasonable person could disagree with).
3. Imply the **ask** (what you want the audience to do/decide).
4. Fit in **one breath** when spoken aloud.

If you cannot write it in one sentence, you do not yet know what the talk is about. Stop and find it.

## Narrative Arcs

### 1. What Is / What Could Be (Nancy Duarte pattern)
Best for: pitches, persuasion, change initiatives, sales.

Oscillate between the current reality ("what is") and a better future ("what could be"). Each swing makes the gap feel larger and the desire to close it stronger. End on the "new bliss" — life after the audience says yes.

```
What is  -> What could be  -> What is  -> What could be  ->  ...  -> Call to action -> New bliss
```

Use when you need to create dissatisfaction with the status quo and pull toward a vision.

### 2. The Pyramid (Minto / answer-first)
Best for: executives, decisions, reports, time-pressed audiences.

State the conclusion FIRST, then the supporting arguments in 3 grouped pillars, then evidence under each. Busy audiences can stop at any level and still get the point.

```
Answer / recommendation
  Argument A  -> evidence
  Argument B  -> evidence
  Argument C  -> evidence
Reinforce the answer
```

Use when the audience wants the bottom line up front and hates suspense.

### 3. Situation - Complication - Resolution (SCR / SCQA)
Best for: status updates, project reports, proposals.

```
Situation     (the stable context everyone agrees on)
Complication  (what changed / what went wrong / the tension)
Question      (the implicit question the complication raises)
Resolution    (your answer / plan) + Next steps
```

Use when you need to justify a decision or explain why action is needed.

### 4. Hero's Journey Lite
Best for: keynotes, inspirational talks, founder stories.

```
Ordinary world -> Catalyst/call -> Struggle -> Insight/turning point -> Transformation -> Lesson for the audience
```

The audience (or a relatable protagonist) is the hero; you are the guide. Use sparingly and only when the emotional payoff justifies the runtime.

## Emotional Mapping

Map one dominant emotion per section so the deck has a felt rhythm, not just logical flow:

| Section | Typical emotion | How to evoke it |
|---------|-----------------|-----------------|
| Hook | Curiosity / surprise | A question, a counterintuitive stat, a vivid scene |
| Stakes | Concern / urgency | Cost of inaction, a deadline, a relatable pain |
| Body | Confidence / clarity | One clean idea per slide, building logically |
| Proof | Trust | Evidence, demo, third-party data, a customer voice |
| Call to action | Hope / resolve | A concrete, achievable next step |
| Close | Conviction | Restated message + one memorable line |

## Opening Patterns (pick one)

- **The provocative question** — "What if everything we believe about X is wrong?"
- **The surprising statistic** — one number, big, with the source.
- **The vivid scene** — drop the audience into a concrete moment.
- **The relatable pain** — name the frustration they live with.
- **The bold claim** — state the core message immediately, then defend it.

Never open with: an agenda, your bio, an apology, or "Thanks for having me."

## Closing Patterns (pick one)

- **The callback** — return to the opening image/question, now resolved.
- **The one ask** — a single, concrete action with a deadline.
- **The vision line** — paint the world after they act.
- **The rule of three** — three short clauses that sum the message.

Put the actual final sentence (the line you want hanging in the air) in the speaker notes verbatim. End on that sentence; only then thank the audience.

## The "So What?" Chain

A strong deck survives the "so what?" test at every step. After drafting, walk slide to slide asking "so what?" — the next slide's title should answer it. If it doesn't, the transition is broken or the slide is filler.
