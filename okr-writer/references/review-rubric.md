# OKR Review Rubric

Use this to grade any draft OKR set before finalizing. Score each item; anything scoring poorly must be rewritten.

## Objective Checklist (per objective)

| Check | Pass criteria |
|-------|---------------|
| Qualitative | Contains no numeric target |
| Single focus | Not two goals joined by "and" |
| Inspirational | Means something to the team |
| Memorable | Recitable from memory, < ~12 words |
| Outcome-oriented | Describes an end state, not an activity |
| Owned | Has a clear team/person |

## Key Result Checklist (per KR)

| Check | Pass criteria |
|-------|---------------|
| Measurable | Has a number / metric |
| Baseline | States where it is today |
| Target | States where it should land |
| Deadline | Within the OKR period |
| Outcome | Measures result, not task (passes inversion test) |
| Non-vanity | Ties to real value |
| Precise | Unit + segment + data source defined |
| Influenceable | Owner can move it this period |

## Set-Level Checklist

| Check | Pass criteria |
|-------|---------------|
| Count | 3-5 objectives max; 2-5 KRs each |
| Balance | Each growth/speed objective has a quality guardrail KR |
| Ambition tagged | Each marked committed vs aspirational |
| No task lists | Initiatives separated from KRs |
| Alignment | Ladders up to a higher-level objective / strategy |

## Scoring Guide

For each KR, assign a quality grade:
- **A** — passes all KR checks. Ship it.
- **B** — measurable and outcome-based but missing baseline or precision. Fix the gap.
- **C** — measurable but a vanity metric or weakly tied to value. Replace or pair with a value KR.
- **F** — a task/output, or has no number. Rewrite using the "so that" ladder in outcome-vs-output.md.

## Fast Triage Questions

1. Could we hit every KR and still fail the objective? → KRs are mismeasured.
2. Could we fail every KR yet "feel" the objective happened? → Objective and KRs are disconnected.
3. Is any KR a deliverable with a ship date? → It's an initiative; move it.
4. Does any KR lack a starting number? → Add a baseline or it can't be graded.
5. Could a clever team game the headline number? → Add a counter-metric.
