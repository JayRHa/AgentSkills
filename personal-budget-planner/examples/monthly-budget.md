# Worked Example: Monthly 50/30/20 Budget

## Profile
Single, net income **$3,800/month**. Has a $600 credit-card balance (24% APR) and $200 in savings. Wants to stop living paycheck-to-paycheck.

## Step 1 — Current spending (from statements)
| Category | Amount | Type |
| --- | --- | --- |
| Rent | $1,300 | Need |
| Utilities + phone | $220 | Need |
| Groceries | $450 | Need |
| Transport (gas, transit) | $180 | Need |
| Insurance | $150 | Need |
| Card minimum | $25 | Need |
| Dining out | $420 | Want |
| Subscriptions (6) | $95 | Want |
| Shopping / fun | $480 | Want |
| Savings | $0 | — |
| **Total spent** | **$3,720** | |

## Step 2 — Map to 50/30/20
- Needs target 50% = $1,900 → actual **$2,325 (61%)** — over.
- Wants target 30% = $1,140 → actual **$995 (26%)** — under.
- Savings/debt target 20% = $760 → actual **$25 (0.7%)** — far under.

Needs are high (housing-driven), and almost nothing goes to savings/debt.

## Step 3 — The plan
- **Cut Wants** by $300: trim dining ($420→$250), cancel 3 unused subscriptions (−$45), shopping ($480→$395).
- **Redirect** that $300 + the existing $80 slack → **$380/month** to savings & debt.
- **Order of operations:** build a $1,000 starter emergency fund first while paying the $25 card minimum, *then* avalanche the 24% card.

## Step 4 — New monthly allocation
| Bucket | New amount | % |
| --- | --- | --- |
| Needs | $2,325 | 61% |
| Wants | $695 | 18% |
| Emergency fund (auto on payday) | $355 | |
| Extra to card | $25 (+min) | |
| **Total** | **$3,800** | 100% |

## Step 5 — Timeline
- Emergency fund hits $1,000 in ~2.5 months (with the $200 head start).
- Then redirect the $355 to the card: $600 balance clears in ~2 months.
- After that: full 3–6 month fund, then investing.

## Automate & review
Set the $355 transfer to fire automatically on payday. Weekly 10-minute check on dining/shopping. Re-budget monthly.
