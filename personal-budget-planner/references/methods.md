# Budgeting Methods

## 50/30/20 (simple, balanced)
Split net income:
- **50% Needs** — rent/mortgage, utilities, groceries, transport, insurance, minimum debt payments.
- **30% Wants** — dining out, entertainment, hobbies, travel, upgrades.
- **20% Savings & extra debt** — emergency fund, retirement, investments, extra principal.

Good default. If Needs exceed 50% (common in high-cost areas), the ratios shift — name that explicitly and adjust the targets rather than pretending.

## Zero-based budget (maximum control)
Every unit of income is assigned a job until **income − all assignments = 0**. Includes savings and debt as "expenses." Forces intentionality; great for getting out of debt or hitting an aggressive savings rate. More effort to maintain.

## Envelope / cash-stuffing (for overspenders)
Cash (or virtual envelopes) allocated per category. When the envelope is empty, spending in that category stops. Powerful for variable categories like dining and groceries where overspending hides.

## Pay-yourself-first (savings-led)
Automate savings/investments on payday, then live on the rest. Simplest way to guarantee a savings rate; pair with a light spending check.

## Sinking funds (for irregular costs)
Save a little monthly toward predictable-but-irregular expenses (car maintenance, annual insurance, holidays, gifts) so they never become a crisis. E.g., $1,200 annual expense → set aside $100/month.

## Choosing
| User profile | Method |
| --- | --- |
| Beginner, wants simple | 50/30/20 |
| Detail-oriented, debt focus | Zero-based |
| Chronic overspender | Envelopes |
| Disciplined, busy | Pay-yourself-first + automation |
| Surprised by big bills | Add sinking funds to any method |
