# Bullet Formulas & Verb Bank

## The impact formula
```
[Strong action verb] + [what you did] + [quantified result or scope] + [optional: how / context]
```

Examples:
- **Reduced** AWS spend **23% ($180k/yr)** by right-sizing idle instances and adding autoscaling.
- **Led** a 6-engineer team to **ship a payments rewrite 2 weeks early**, cutting checkout errors 35%.
- **Automated** weekly reporting with Python, **saving ~10 analyst-hours/week**.

## Alternative frames
- **XYZ (Google formula):** "Accomplished [X] as measured by [Y] by doing [Z]."
- **Problem → Action → Result:** good when the challenge itself is impressive.
- **Scope-led:** when no metric exists — "Owned the EU billing pipeline serving 12k merchants."

## Quantification cheatsheet (when there's no obvious number)
| Dimension | Example |
| --- | --- |
| Money | revenue, cost saved, budget managed |
| Percent | growth, error reduction, efficiency |
| Time | faster, sooner, hours saved/week |
| Scale | users, requests, $ volume, team size |
| Frequency | "daily," "across 5 markets" |
| Rank | "top 3 of 40," "#1 region" |

## Strong action verbs by intent
- **Built/Created:** built, designed, developed, engineered, launched, shipped, architected, established.
- **Improved:** optimized, streamlined, accelerated, reduced, increased, automated, refactored.
- **Led:** led, directed, coordinated, mentored, drove, spearheaded, owned.
- **Analyzed:** analyzed, diagnosed, evaluated, modeled, forecasted, investigated.
- **Delivered:** delivered, negotiated, closed, secured, resolved, exceeded.

## Verbs to avoid
"Responsible for," "helped with," "worked on," "involved in," "assisted," "various," "duties included." These describe presence, not impact.
