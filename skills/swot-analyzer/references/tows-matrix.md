# TOWS Cross-Matrix — Turning SWOT into Strategy

A SWOT lists factors. A TOWS matrix combines them to generate strategies. It is the difference between analysis and decision-making. Always run it.

## The four cells

```
                 STRENGTHS (S)              WEAKNESSES (W)
             +---------------------------+---------------------------+
 OPPORTUNITIES|  S-O: ATTACK              |  W-O: IMPROVE             |
   (O)        |  Maxi-Maxi                |  Mini-Maxi                |
             |  Use strengths to grab    |  Fix/borrow to qualify    |
             |  opportunities. Offense.  |  for opportunities.       |
             +---------------------------+---------------------------+
 THREATS (T)  |  S-T: DEFEND              |  W-T: SURVIVE             |
             |  Maxi-Mini                |  Mini-Mini                |
             |  Use strengths to blunt   |  Reduce exposure; retreat,|
             |  threats. Build moats.    |  hedge, or exit. Defense. |
             +---------------------------+---------------------------+
```

## How to build it

1. Take the top-ranked items from each SWOT quadrant (use Impact x Confidence).
2. For each cell, pair specific internal factors with specific external factors.
3. Write a strategy that names BOTH factors. "Leverage [strength] to capture [opportunity] by [action]."
4. Discard generic strategies that don't reference real factors.

## Strategy types in depth

### S-O — Attack (Maxi-Maxi)
The growth engine. Match your biggest strength to your biggest opportunity.
- Pattern: "Because we have S, we can be first/best at O."
- Example: Strength = best-in-class onboarding (low time-to-value). Opportunity = incumbent abandoning SMB tier. Strategy = aggressive self-serve SMB land grab while incumbent retreats; target their churning accounts.

### S-T — Defend (Maxi-Mini)
Protect the core. Use strengths to neutralize external threats.
- Pattern: "We use S to make T not matter."
- Example: Strength = proprietary dataset. Threat = well-funded new entrant. Strategy = deepen the data moat with exclusive partnerships so the entrant cannot replicate the core advantage.

### W-O — Improve (Mini-Maxi)
Invest to qualify. A weakness is blocking you from an opportunity — close the gap.
- Pattern: "We must fix W (build/hire/partner/acquire) to capture O."
- Example: Weakness = no mobile app. Opportunity = mobile-first buyer segment surging. Strategy = ship mobile MVP in two quarters or white-label a partner's app to enter now.

### W-T — Survive (Mini-Mini)
Damage control. Where a weakness meets a threat, you are exposed — de-risk.
- Pattern: "W + T together could sink us; reduce both."
- Example: Weakness = single-customer revenue concentration (60%). Threat = that customer evaluating a competitor. Strategy = emergency diversification: lock a multi-year renewal, accelerate pipeline, cap exposure.

## From strategy to action

Every selected strategy must become one or more actions with:
- **What** — the concrete move.
- **Why** — which TOWS pairing it answers.
- **Owner** — a role or person.
- **Horizon** — Now / 90 days / 12 months.
- **Metric** — how you know it worked.

## Sequencing rule

Do not pursue every strategy at once. Sequence:
1. **W-T survival** items first if any are existential (they cap your downside).
2. **S-O attack** bets that compound (your offense).
3. **S-T** moats to protect the gains.
4. **W-O** investments that unlock the next wave.
