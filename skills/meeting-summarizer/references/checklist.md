# Pre-Delivery Quality Checklist

Run through this before returning a meeting summary. The first three are blocking.

## Blocking checks

- [ ] **No orphan actions.** Every action item has an Owner cell filled — a real name or `UNASSIGNED`. Never blank, never guessed.
- [ ] **No hallucinations.** No owner, date, figure, or decision appears that isn't supported by the source.
- [ ] **Decisions are in Decisions.** Scan the source for settle/approve/agree/choose cues; confirm each landed in the Decisions section, not buried in discussion.

## Accuracy checks

- [ ] All numbers, currency amounts, percentages, version numbers, and proper nouns are copied exactly.
- [ ] Relative dates ("next Tuesday", "EOD") converted to absolute dates ONLY when a meeting date is known; otherwise left as-is.
- [ ] Pronouns resolved to named owners using the attendee list and speaker labels.
- [ ] Conditionals preserved ("only if budget approved", "pending legal").

## Structure & readability checks

- [ ] TLDR is 1–3 sentences and stands alone.
- [ ] Action items are verb-first imperatives.
- [ ] Empty sections removed (except Action Items, which always renders).
- [ ] Duplicates merged; filler and small talk removed.
- [ ] Metadata line present (date/attendees, with "not stated" where applicable).

## Scope & tone checks

- [ ] Length matches input size (don't write a page for a 5-line standup).
- [ ] Tone matches context (neutral/professional for client calls).
- [ ] Acronyms spelled out once for external audiences.

## Final pass

- [ ] Re-read the source once more for any committed task you missed — missed action items are the most common and most costly error.
