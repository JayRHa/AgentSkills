# Card Formulation Principles

Distilled from SuperMemo's *20 Rules of Formulating Knowledge* and spaced-repetition research.

## The core rules
1. **Understand before you memorize.** Cards for misunderstood material are worse than useless.
2. **Minimum information principle.** Make each item as simple as possible — but no simpler. Simple items are easier to schedule and retain.
3. **Atomic.** One fact per card. If a card has "and", a comma list, or two ideas, split it.
4. **Active recall, not recognition.** The prompt must force retrieval. Avoid yes/no and multiple choice.
5. **Cloze deletion** for facts that live inside a sentence. Delete the key term, keep enough context to be unambiguous.
6. **Avoid sets and enumerations.** "List all X" is hard to grade and recall. Convert to multiple cards, cloze each item, or build an ordered mnemonic.
7. **Unambiguous.** Exactly one acceptable answer. Add a minimal context tag if needed (e.g. "(chemistry)").
8. **No interference.** Cards that look alike get confused. Make similar facts visibly distinct.
9. **Personalize & connect.** Tie facts to examples, images, and things you already know — increases retrieval strength.
10. **Keep the question short.** Long stems slow reviews and bury the cue.

## Card types

| Type | When | Format |
| --- | --- | --- |
| Basic | discrete fact | Front = question, Back = answer |
| Basic (+reverse) | bidirectional recall | also tests Back→Front |
| Cloze | fact in context | `... {{c1::hidden}} ...` (multiple `c1/c2/...` per card) |
| Type-in | spelling/exactness matters | answer typed and checked |

## Spacing
Let an SRS (Anki, etc.) schedule reviews on an expanding interval. Don't cram; review just as recall starts to fade. New cards: ~10–20/day is sustainable for most learners.

## Quality gate per card
- [ ] One fact only
- [ ] Forces recall (not recognition)
- [ ] Exactly one correct answer
- [ ] Question doesn't leak the answer
- [ ] Short and clear
- [ ] Won't be confused with a sibling card
