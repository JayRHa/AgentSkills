# Worked Example: Proofreading a Project Update Email

This shows the full workflow end to end: input, the passes, and the final deliverable.

## Input (original)

> Hi team,
>
> I wanted to reach out in order to give you a quick update on the project. Due to the fact that we recieved the new requirements late, the team have decided to push the deadline. There is a large number of tasks that still needs to be completed, and me and Sarah will be focusing on the the backend this week.
>
> The end result is that we are going to try and finish the API by friday. Its going to be tight but I think we can do it. Please RSVP if you can join the standup, it would really help alot.
>
> Thanks,
> Alex

## Pass 1 - Correctness
- "recieved" → "received" (spelling)
- "the team have decided" → "the team has decided" (US collective noun = singular)
- "that still needs" → "that still need" (agreement with plural "tasks")
- "me and Sarah" → "Sarah and I" (pronoun case + conventional order)
- "the the backend" → "the backend" (doubled word)
- "Its going to" → "It's going to" (it's = it is)
- "friday" → "Friday" (capitalize day)
- "alot" → "a lot" (spelling)
- "please RSVP" → "please respond" (RSVP already means please respond; or keep "RSVP" and drop "please")

## Pass 2 - Clarity
- "try and finish" → "try to finish" (standard form)
- comma splice "it would really help" joined by comma → split into its own sentence

## Pass 3 - Concision
- "reach out in order to give you a quick update on" → "give you a quick update on"
- "Due to the fact that" → "Because"
- "There is a large number of tasks that still need" → "Many tasks still need"
- "The end result is that we are going to" → "We aim to"
- "really help a lot" → "help a lot" (drop filler "really")

## Pass 4 - Consistency
- US English confirmed; "Friday" capitalized; tone kept casual and friendly.
