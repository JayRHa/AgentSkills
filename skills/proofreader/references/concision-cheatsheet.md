# Concision Cheat Sheet

Use during the concision pass. Cut clutter while preserving meaning, nuance, and politeness. Never sacrifice clarity for brevity.

## Wordy Phrase → Tight Replacement

| Wordy | Concise |
|-------|---------|
| in order to | to |
| due to the fact that | because |
| in the event that | if |
| at this point in time | now |
| in the near future | soon |
| a large number of | many |
| the majority of | most |
| has the ability to | can |
| is able to | can |
| make a decision | decide |
| give consideration to | consider |
| conduct an investigation | investigate |
| in spite of the fact that | although |
| with regard to / in regard to | about / regarding |
| for the purpose of | to / for |
| in the process of | (often deletable) |
| it is important to note that | (often deletable) |
| there is / there are … that | (recast: "Several files need review.") |
| on a daily basis | daily |
| at the present time | now / currently |
| in close proximity to | near |
| each and every | each / every |
| end result | result |
| past history | history |
| future plans | plans |
| absolutely essential | essential |
| completely eliminate | eliminate |
| basic fundamentals | fundamentals |
| advance planning | planning |
| close scrutiny | scrutiny |

## Filler Words to Delete (When They Add Nothing)
- very, really, quite, rather, somewhat, basically, actually, literally
- just, simply, that (when optional), in fact, of course
- needless to say, it goes without saying
- I think / I believe / in my opinion (cut when the whole text is clearly the author's view)

## Redundancy Patterns (Pleonasms)
Delete the redundant element:
- free gift, added bonus, new innovation, unexpected surprise
- close proximity, exact same, final outcome, joint collaboration
- revert back, return back, repeat again, merge together, combine together
- ATM machine, PIN number, please RSVP
- 12 noon, 12 midnight

## Structural Tightening
- **Nominalizations → verbs**: "perform an analysis of" → "analyze"; "provide assistance" → "help."
- **Expletive openers**: "There are many reasons that explain…" → "Many reasons explain…"
- **Negatives → positives**: "not different" → "the same"; "did not remember" → "forgot."
- **Hidden verbs**: "is suggestive of" → "suggests."
- **Prepositional pileups**: rewrite chains of "of the … in the … for the."

## Concision Guardrails (When NOT to Cut)
- Keep hedges that carry real meaning in technical/legal/scientific writing ("may," "approximately," "in most cases").
- Keep politeness markers in interpersonal writing ("could you," "please," "thank you").
- Keep words needed for rhythm, emphasis, or the author's voice.
- Do not compress two distinct ideas into one if it creates ambiguity.
- Brevity is a means to clarity, not the goal itself.
