# Learning Science Principles

Evidence-based techniques that make study plans effective. Bake these into every plan.

## High-impact techniques

| Technique | What it means | How to schedule it |
| --- | --- | --- |
| **Active recall (retrieval practice)** | Test yourself instead of re-reading | End every session with recall: flashcards, closed-book summary, practice questions |
| **Spaced repetition** | Review at expanding intervals just as memory fades | Revisit M1 in week 2, week 4, week 6 — not all at once |
| **Interleaving** | Mix related topics rather than blocking one | In later weeks, practice mixed-topic problem sets |
| **Deliberate practice** | Targeted work at the edge of your ability with feedback | Practice the specific sub-skills you get wrong, not what's already easy |
| **Elaboration** | Explain *why/how*, connect to prior knowledge | Add "explain it in your own words" tasks |
| **Concrete examples + projects** | Apply abstract ideas to real artifacts | Make milestone deliverables real projects |

## Lower-impact (use sparingly)
- Highlighting and re-reading feel productive but are weak; convert them into recall.
- Massed practice (cramming) gives short-term gains that fade fast.

## Session template (≈1 hour)
1. **5 min** — recall last session (no notes).
2. **20–25 min** — new input (read/watch a focused chunk).
3. **25–30 min** — active practice / exercises on the new material.
4. **5 min** — self-quiz + note what to review next time.

## Pacing
- Spacing beats volume: 5×1hr across a week >> one 5hr block.
- New-material load: keep it sustainable; reserve time for accumulating review.
- Apply the buffer: plan ~85% of available hours; the rest absorbs slippage and review.

## When behind
Cut **scope**, never **review**. Forgotten foundations cost more than skipped advanced topics.
