# Email Template (fill in)

Replace every <bracket>. Delete blocks you don't need. Keep it tight.

```
To:      <recipient(s)>
Cc:      <only those who need to act or be informed>
Subject: <Action/Topic> <object> <by date if applicable>

<Greeting matched to formality — e.g., "Hi <Name>,">

<Context: one line. Why you're writing / link to prior thread.>

<Core message: 1–3 sentences, most important first (BLUF).>

<Call to action: the specific ask + owner + deadline.>
  e.g., "Could you <action> by <day, date, time + tz>?"
  Offer options if scheduling: "<Tue 2pm CET> or <Wed 10am CET>?"

<Optional offer to help: "Happy to <call / clarify / send X> if useful.">

<Sign-off matched to formality>,
<Your name>
<Signature block: role, org, contact — if external/formal>
```

## Quick variants to keep handy
- **Warmer version:** add a one-line personal opener and a collaborative close.
- **Firmer version:** state the deadline and consequence plainly; drop softeners.
- **Shorter version:** subject + one sentence of context + the CTA. Done.
