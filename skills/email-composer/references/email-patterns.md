# Email Patterns

Each pattern lists: when to use, structure, a subject-line formula, and a template. Adapt wording to the calibrated tone (see tone-guide.md).

## Subject-Line Rules (apply to all patterns)
- Length: aim for 30–50 characters; hard cap ~60 so it isn't truncated on mobile.
- Front-load the keyword: `[Action/Topic] + [object] + [deadline]`.
- Be specific and scannable. Avoid "Hi", "Quick question", "Touching base", "Following up" alone.
- Signal the ask type with a verb or tag: `Approval needed:`, `Action required:`, `FYI:`, `Decision:`, `Reminder:`.
- Include the deadline when one exists: `... by Thu Jun 12`.
- Examples:
  - Bad: "Update" -> Good: "Status: Mercury rollout 60% done, 1 blocker"
  - Bad: "Meeting" -> Good: "Confirm: kickoff Tue 2pm or Wed 10am?"

## 1. Request / Ask
Use when you need an action, decision, information, or a favor.

Structure: context (1 line) -> the ask (specific) -> why it matters / what's in it for them -> deadline -> offer to help.

Subject: `[Action verb] needed: <object> by <date>`

Template:
```
Hi <Name>,

<One-line context tying to a shared goal or prior thread.>

Could you <specific action> by <day, date/time>? <One line on why it matters or the benefit.>

Happy to <provide info / hop on a call> if that helps.

Thanks,
<You>
```

## 2. Follow-up / Nudge
Use when a prior email went unanswered or a deadline approaches. Stay light on the first nudge, firmer later.

Structure: reference prior message -> restate the single ask -> new easy CTA -> graceful out.

Subject: reply in-thread (`Re: ...`) or `Reminder: <ask> by <date>`

Template (first, gentle):
```
Hi <Name>,

Just floating this back to the top of your inbox. Were you able to <action> from my note on <date>?

No rush if you're swamped — even a one-line reply on timing would help me plan.

Thanks,
<You>
```

Template (later, firmer but polite):
```
Hi <Name>,

Following up again on <ask>. We need this by <date> to keep <project/outcome> on track.

Can you confirm whether that timeline works? If there's a blocker on your end, tell me and I'll help clear it.

Thanks,
<You>
```

## 3. Decline / Say No
Use to turn down a request, invitation, or proposal without burning the relationship.

Structure: thank/acknowledge -> clear no -> brief honest reason (optional) -> alternative or door left open.

Subject: `Re: <their topic>` or `<Topic>: not this round`

Template:
```
Hi <Name>,

Thank you for thinking of me for <thing> — I appreciate it.

I'm not able to <commit/take this on> right now because <brief reason>. I want to be straight rather than overpromise.

<Optional: alternative — "Could <person> help?" / "Let's revisit in Q4.">

Best,
<You>
```

## 4. Apology
Use when something went wrong on your side. Own it once, fix it, don't grovel.

Structure: acknowledge specifically -> take responsibility -> state the fix/next step -> brief forward look.

Subject: `Apology + fix: <issue>`

Template:
```
Hi <Name>,

I'm sorry for <specific issue> — that was on me and I understand the impact on <consequence>.

Here's what I'm doing: <concrete fix> by <date>. To prevent a repeat, <safeguard>.

Thank you for your patience. Happy to discuss if useful.

<You>
```

## 5. Status Update
Use for recurring or milestone progress reports. Lead with the headline.

Structure: headline (on track / at risk / blocked) -> what's done -> what's next -> any ask/blocker.

Subject: `Status: <project> — <on track | at risk | blocked>`

Template:
```
Hi <team/Name>,

Headline: <project> is <on track / at risk / blocked>.

- Done: <key items>
- Next: <upcoming items, owner, date>
- Need from you: <decision/resource> by <date> (or "nothing — FYI")

Details in <link>.

<You>
```

## 6. Introduction / Connecting Two People
Use to introduce two contacts (double opt-in is best practice).

Structure: name both -> one line on each -> why connect -> hand off.

Subject: `Intro: <Person A> <> <Person B>`

Template:
```
Hi <A> and <B>,

Great to connect you two.

<A> — <one line: who B is and why relevant to A.>
<B> — <one line: who A is and why relevant to B.>

I'll step back and let you take it from here. <Optional: suggested next step.>

Best,
<You>
```

## 7. Cold Outreach
Use for a first contact with no prior relationship. Earn the reply; respect their time.

Structure: relevant hook (show you did homework) -> who you are (1 line) -> the value/ask -> tiny, low-friction CTA.

Subject: `<Specific relevant hook>` (not "Partnership opportunity")

Template:
```
Hi <Name>,

<Specific, researched hook — a recent post, launch, mutual contact, or problem they likely have.>

I'm <you/role> at <org>; we <one line of relevant value>.

Would a 15-minute call next week make sense to explore <specific topic>? If not the right person, could you point me to who is?

Thanks,
<You>
```

## 8. Escalation
Use when normal channels stalled and you must raise the issue. Stay factual, not emotional.

Structure: state issue + impact -> timeline of what's been tried -> specific decision/help needed -> deadline.

Subject: `Escalation: <issue> blocking <outcome>`

Template:
```
Hi <Name>,

I'm escalating <issue> as it's now blocking <outcome/deadline>.

Timeline: <date> <action taken>; <date> <follow-up>; still unresolved.

Decision needed: <specific choice> by <date>. Without it, <consequence>.

I'm available <times> to resolve this quickly.

<You>
```
