# Deck Review Checklist

Run in Step 6. Two passes: per-slide, then whole-deck. Mark each item PASS / FIX.

## Per-Slide Pass (run on every slide)

- [ ] **Assertion title** — the title makes a point, not just names a topic. ("Onboarding broke, so sales fell" not "Onboarding".)
- [ ] **One idea only** — the slide advances exactly one step of the argument. If it has two ideas, split it.
- [ ] **Minimal on-slide text** — a phrase or single visual, no paragraphs. Audience can grasp it in <5 seconds.
- [ ] **Speaker notes present** — written as spoken words, 30-90 seconds, NOT a copy of the slide text.
- [ ] **Slide != notes** — on-slide content and spoken words do not duplicate each other.
- [ ] **Data has a verdict** — any chart/number states what it proves (usually in the title).
- [ ] **Transition** — one line connecting to the next slide; answers the previous slide's "so what?".
- [ ] **Earns its place** — removing it would weaken the core message. If not, cut it.

## Whole-Deck Pass

- [ ] **Audience defined** — who, what they know, what they care about, what they fear.
- [ ] **Single core message** — one declarative sentence; stated early AND restated at the end.
- [ ] **Clear ask** — one concrete call to action (verb + object + deadline).
- [ ] **Arc, not list** — a recognizable narrative structure (What is/What could be, Pyramid, SCR, Hero's journey).
- [ ] **Strong open** — hook in the first slide; no agenda/bio/apology opener.
- [ ] **Strong close** — restated message + memorable line; "Thank you" comes after the message, not instead of it.
- [ ] **Emotional rhythm** — sections have distinct emotional beats, not uniform flatness.
- [ ] **Pacing fits time** — slide count vs. time budget is sane (run scripts/pacing.py).
- [ ] **No orphan data** — every chart ties back to the argument.
- [ ] **Cuttable slides cut** — when in doubt, fewer slides.

## Red Flags (auto-fail, must fix)

| Red flag | Fix |
|----------|-----|
| Title is a single noun/topic | Rewrite as a full assertion |
| Bullet wall (5+ lines of text) | Split into multiple slides or move to notes |
| Chart with no takeaway | Add the conclusion to the title |
| No call to action | Add one concrete next step |
| Speaker notes = slide bullets | Rewrite notes as spoken prose |
| Deck ends on "Questions?" only | Add a closing message line before it |
| Agenda as slide 1 | Replace with a hook |

## Quick Scoring

Count FIX items. 0 = ship it. 1-3 = polish. 4+ = restructure before delivering.
