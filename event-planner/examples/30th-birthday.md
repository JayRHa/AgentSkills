# Worked Example: 40-Guest 30th Birthday

## Frame
- **Type/vibe:** relaxed evening party, casual-festive.
- **Date:** 6 weeks out, a Saturday.
- **Guests:** 40 (expect ~10% no-show → plan for ~36).
- **Budget:** $2,000.
- **Location:** rented community hall (host's apartment too small); outdoor patio optional.

## Budget envelope ($2,000)
| Category | Budget | Notes |
| --- | --- | --- |
| Venue (hall, 5 h) | $450 | Includes tables/chairs |
| Food (taco bar caterer) | $640 | ~$16/head × 40 |
| Drinks | $300 | BYO-supplemented; ~1/hr/guest |
| Cake + dessert | $120 | |
| Décor + supplies | $150 | Lights, balloons, tableware |
| Music (playlist + speaker rental) | $80 | DJ over budget — self-DJ |
| **Contingency** | **$260 (13%)** | |
| **Total** | **$2,000** | |

## Timeline (backward)
- **Wk 6:** book hall, confirm budget + guest list.
- **Wk 4:** send invites (RSVP by wk 2), book caterer, order cake.
- **Wk 2:** confirm headcount, buy décor + non-perishable drinks, rent speaker.
- **Wk 1:** reconfirm caterer + hall, finalize playlist, recruit 2 helpers.
- **Day −1:** pick up cake, chill drinks, pack supplies + emergency kit.
- **Day:** setup → party → teardown.

## Run-of-show (day)
| Time | Block | Owner |
| --- | --- | --- |
| 3:00 | Helpers arrive, set tables/décor | Point person (friend, not host) |
| 5:00 | Caterer arrives, food staged, music on | Point person |
| 5:30 | Doors / welcome drinks | Host |
| 6:30 | Taco bar opens | Caterer |
| 8:00 | Cake + toast | Host's partner |
| 8:30 | Music / dancing | — |
| 10:30 | Wind down | Point person |
| 11:00 | Teardown, settle vendor balance | Point person + helpers |

## Contingencies
- **Weather:** patio is a bonus, not the plan — everything works indoors.
- **No-shows/extra guests:** caterer set for 40; over-order drinks by 10%.
- **Point person** (not the host) owns vendor coordination so the host can enjoy it.
- **Emergency kit:** scissors, tape, lighter, spare cutlery, napkins, phone charger, first-aid, trash bags.

> Confirm venue capacity, caterer quote, and any alcohol rules for the hall directly before booking.
