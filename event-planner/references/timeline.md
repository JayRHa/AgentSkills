# Backward-Planned Timelines

Always plan **from the event date back to today**. Below are typical lead times — compress proportionally for smaller events.

## Wedding / large event (6–12 months)
| When | Milestones |
| --- | --- |
| 9–12 mo | Set date, budget, guest count; book venue + caterer + photographer |
| 6–9 mo | Book key vendors (music, florist), order attire, send save-the-dates |
| 3–4 mo | Send invitations, finalize menu, plan run-of-show, arrange transport/lodging |
| 1 mo | Collect RSVPs, finalize headcount, confirm all vendors, seating plan |
| 1 wk | Reconfirm everything, final payments, pack emergency kit, brief point person |
| Day | Run-of-show, setup, event, teardown |

## Party / birthday (3–6 weeks)
| When | Milestones |
| --- | --- |
| 4–6 wk | Date, budget, guest list, book/reserve space |
| 2–3 wk | Send invites with RSVP date, order cake, plan food & drinks, line up entertainment |
| 1 wk | Confirm RSVPs and final count, buy décor/supplies, shop non-perishables |
| 1–2 d | Cook/prep, pick up perishables, set up space, confirm helpers |
| Day | Final setup, host, cleanup |

## Dinner party (1–2 weeks)
| When | Milestones |
| --- | --- |
| 1–2 wk | Invite, confirm date + dietary needs, plan menu |
| 2–3 d | Shop non-perishables, prep make-ahead dishes |
| 1 d | Shop fresh, prep, set table |
| Day | Final cooking, last-hour tidy, host |

## Run-of-show template (day-of)
| Time | Block | Owner |
| --- | --- | --- |
| T−3h | Vendor arrival / setup | Point person |
| T−1h | Final checks, food staged, music on | Host + helper |
| T+0 | Guests arrive, welcome drinks | Host |
| … | Key moments (speeches, cake, activities) | Assigned |
| T+end | Wind-down, teardown, vendor payment | Point person |

Assign a name to every block. The host should not be the day-of coordinator.
