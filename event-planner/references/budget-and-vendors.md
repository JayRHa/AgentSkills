# Budget Splits & Vendor Checklist

## Typical budget allocation
Percentages vary by event, but these are useful starting splits. Always add a **10–15% contingency** on top.

### Wedding (rough)
| Category | % of budget |
| --- | --- |
| Venue + catering | 40–50% |
| Photography/video | 10–12% |
| Attire + beauty | 8–10% |
| Flowers + décor | 8–10% |
| Music/entertainment | 8–10% |
| Stationery, cake, favors | 5% |
| Transport, misc | 5% |
| **Contingency** | **10–15%** |

### Party (rough)
| Category | % |
| --- | --- |
| Food & drink | 40–50% |
| Venue/space | 15–25% |
| Entertainment/activities | 10–15% |
| Décor | 10% |
| Cake/dessert | 5–10% |
| **Contingency** | **10–15%** |

## Don't forget the hidden costs
Service charges, gratuities (often 18–22%), taxes, delivery/setup fees, corkage, overtime, rentals (tables, chairs, linens, glassware), insurance, parking, coat check, and cleanup.

## Food & drink quantities (rules of thumb)
- **Drinks:** ~1 drink per guest per hour; first hour slightly higher.
- **Appetizers:** 4–6 pieces/person for a cocktail hour; more if it replaces a meal.
- **Buffet:** budget ~1.5 portions/person (people take more than a plated serving).
- **Always over-cater slightly** (~10%) — running out is worse than leftovers.

## Reminders
Confirm capacities, contracts, and live prices directly with vendors. For events with alcohol service, amplified sound, road closures, or large crowds, check local permits/licensing and consider professional event/liability insurance.
