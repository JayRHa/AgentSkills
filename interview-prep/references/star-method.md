# The STAR Method

STAR turns a vague "tell me about a time…" into a tight, evidence-backed story.

| Letter | What | Time budget | Tip |
| --- | --- | --- | --- |
| **S — Situation** | The context, briefly | ~15% | Just enough to understand the stakes |
| **T — Task** | Your specific responsibility/goal | ~10% | Make clear what *you* owned |
| **A — Action** | What *you* did (not the team) | ~50% | First person, specific steps, your decisions |
| **R — Result** | The outcome, quantified | ~25% | Numbers + what you learned |

## Rules
- **Say "I", not "we".** Interviewers score *your* contribution. Use "we" for context, "I" for action.
- **Quantify the result.** "Cut response time 40%", "saved 8 hrs/week", "retained the account".
- **Add a reflection** for failure/learning questions: what you'd do differently.
- **Keep it 90 s–2 min.** Practice trimming the Situation — that's where people overspend.

## Build a reusable story bank
Pick 5–6 experiences and pre-tag each with the competencies it can demonstrate, so you can map an unexpected question to a ready story:

| Story | Leadership | Conflict | Failure | Ambiguity | Impact | Influence |
| --- | --- | --- | --- | --- | --- | --- |
| Launched X feature | ✓ | | | ✓ | ✓ | |
| Defused a client escalation | | ✓ | | | ✓ | ✓ |
| Project that missed its deadline | | | ✓ | ✓ | | |

When asked "tell me about a conflict", you already know which story to reach for — and how to angle it.

## Common behavioral prompts STAR answers
- "Tell me about a time you disagreed with a manager/teammate."
- "Describe a project that failed."
- "Tell me about a time you had to work with limited information."
- "Give an example of when you influenced without authority."
- "Tell me about your proudest accomplishment."
